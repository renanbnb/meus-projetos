## Como eu trabalho neste repo

Tento manter commits no padrão Conventional Commits:

| Prefixo | Quando uso |
|---------|-----------|
| `feat:` | quando adiciono alguma coisa nova |
| `fix:` | quando corrijo algo que estava errado |
| `docs:` | quando mudo só documentação ou README |
| `refactor:` | quando reescrevo sem mudar comportamento |

Por enquanto está tudo na `main` porque os projetos são pequenos. Quando começar algo maior, vou usar branches por feature.
